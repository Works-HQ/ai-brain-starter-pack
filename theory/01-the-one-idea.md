# The mental model: from a chat to an agent with a desk

You already know Claude.ai. You've used chats. You've used Projects, where you upload a few reference docs and Claude keeps them in mind while you talk.

Cowork is one shift away from that. Same Claude. New posture.

A Project is a chat with reference docs. Claude can read what you gave it and answer your questions. When the conversation ends, the work scrolls away in the thread. Tomorrow you start over.

Cowork is an agent with a desk. The desk is a folder on your computer. Claude can read everything in it AND write back to it. The work doesn't vanish when you close the tab. It stays on the desk as files you keep.

That's the whole jump. Read-only reference becomes a read-write workspace.

## The folder is the project

Point Cowork at a folder and that folder is the workspace. Everything Claude knows lives there. Everything Claude produces lands there. No hidden state, no uploads to manage, no "which Project was that in again". The folder is the thing. You can open it in Finder, back it up, move it, share it. It's yours.

> **You don't just get an answer now. You get the thing.**
> Ask a Project to "draft the follow-up email" and you get text in a chat you then copy out. Ask Cowork and it writes the draft to a file on the desk, named and saved, ready to open. It does the work and leaves the output where you can find it.

## about-me.md is your standing context

In Projects you had a custom-instructions box. You typed who you are and how you want Claude to behave, and it sat in a settings panel you rarely reopened.

In Cowork that same idea becomes a file at the root of your folder: `about-me.md`. Claude reads it at the start of every session. It's your standing context: who you are, what you do, how you like things written.

The key difference is small and it changes everything. It's a file you own, and Claude can read AND update it. When you tell Claude "actually, I always sign off as 'Cheers'", that can go straight into `about-me.md`. The settings box never learned. The file does. And because it lives in the folder, it travels with the project.

## The moment it clicks

Picture a freelance consultant with two clients. Week one, they tell Claude the basics and put them in `about-me.md`: their tone, their two clients, how they write proposals.

Week two, they say "draft a check-in note for the client." They don't re-explain who the client is, what the engagement is, or how they write. Claude has already read the desk. The draft comes back in their voice, with the right context baked in, no briefing required.

That's the moment. Claude walked into the task already knowing the background, because the background was sitting on the desk the whole time.

> **Safety note:** While you're learning, point Cowork at a folder of copies, not your only copy of anything. An agent that can write can also overwrite. Build trust first, then graduate to live files.
