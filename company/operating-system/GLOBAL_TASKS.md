### How to use this

- Capture fast, sort later. Drop a task under "Today" or "This week" without overthinking. The morning sweep re-sorts.
- One line per task. Add `(project: X)` so it can be filed, and `(due: date)` if it is time-bound.
- Do not keep a separate to-do app running alongside this. One list. This one.
- When you finish something, move it to Done with the date. The weekly reflection reads Done to see what actually shipped.
