### Why this file earns its place

A scheduled task that fires on a timer and does nothing with what it finds is not a loop, it is a cron job with no memory. A loop holds a target, checks where things actually stand against it, works the gap, and keeps what it learns somewhere the next run will read. Debrief and reflect are the two loops this pack ships with. Add your own row once a workflow has run on a real cadence, done real work, and been reviewed, not before. If a row has no real target and nobody is checking its "done when", delete the row. An aspirational loop clutters this register the same way a stale file clutters the brain.
