### How to use this

- This file is deliberately short-lived. It is the "what is happening now" layer that sits on top of the slow-changing brain files.
- When you run a debrief or a weekly update, keep this current. A stale current-context file is worse than none, it makes the AI confidently wrong.
- The morning sweep reads this to understand the week's shape before it builds your day.
